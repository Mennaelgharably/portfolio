Medical Guideline Q&A

Hybrid RAG for clinical decision support. Built for the AI Hackathon, Aug 2026.

Problem
Clinical questions need answers tied to real guidelines. The system answers only from uploaded medical guideline PDFs and declines when the evidence is weak.
What I built
  • Hybrid retrieval combining FAISS (PubMedBERT embeddings) and BM25, fused with Reciprocal Rank Fusion.
  • A confidence gate that refuses to answer before any LLM call when retrieval evidence is weak.
  • Grounded generation (Groq gpt-oss-120b) with numbered citations mapped to verified document, page, and section metadata.
  • Automated evaluation (Citation Accuracy, Precision@k, Faithfulness) and a Streamlit UI for PDF upload and Q&A.

Document Intelligence System

Multi-format RAG Q&A app. Capstone for the Tips Hindawi Challenge, Jun–Jul 2026.

Problem
Answering questions from PDF, DOCX, and TXT files with answers that point back to their sources.
What I built
  • A full RAG pipeline with column-aware PDF extraction, local MiniLM embeddings, and FAISS vector search.
  • Dynamic retrieval sizing and context expansion around strong matches.
  • Grounded answers (Llama 3.3 70B via Groq) with full source citations.
  • Deployed as a free, public Streamlit web app.
