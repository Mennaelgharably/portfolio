## About this site

A static website built with plain HTML and CSS, with no frameworks or build step. It is responsive, keyboard accessible, and supports light and dark mode.

- `index.html`: page content
- `style.css`: styling and color tokens
- `Menna_Tullah_Mohamed_CV.pdf`: downloadable CV

To view it locally, open `index.html` in a browser.
